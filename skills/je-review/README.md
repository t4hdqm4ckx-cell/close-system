# JE review skill

Review criteria, SOX-relevant attributes, pattern detection rules, and output format for journal entry quality control during the month-end close.

## What this skill covers

- Completeness checks (description, support doc, preparer, post date)
- Accuracy checks (debits equal credits, valid account combinations, directional consistency)
- Authorization checks (reviewer requirements by dollar threshold)
- Pattern detection rules (round numbers, weekend posting, recurring identical amounts, late posting, unusual account combinations)
- Triage by severity (high/close-blocking, medium, low)

## Used by

JE Reviewer Agent (primary).

## Trigger phrases

"Review these journal entries", "check this JE", "flag suspicious entries", "SOX JE review", "missing support doc", "weekend posting", "round number flag"
