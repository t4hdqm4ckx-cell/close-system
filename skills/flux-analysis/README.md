# Flux analysis skill

Methodology, commentary templates, driver attribution logic, and output format for month-over-month and budget-vs-actual variance analysis at the GL level.

## What this skill covers

- MoM and BvA trigger tests
- First-pass commentary structure (driver, trend, action sentences)
- Commentary templates by account category (subscription revenue, advertising, content amortization, marketing, salaries, CDN)
- Driver attribution hierarchy (JE log → rec adjustments → driver data → external context → unexplained)
- Anomaly detection (sign flips, step changes, correlation breaks)
- Sign conventions for favorable/unfavorable reporting
- Flux file format (xlsx)

## Used by

Flux & Variance Agent (primary). Close Reporting Agent references flux commentary when assembling the executive memo and board slides.

## Trigger phrases

"Run flux analysis", "write variance commentary", "explain this variance", "what drove the change", "flag material variances", "MoM analysis", "BvA analysis"
