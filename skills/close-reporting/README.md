# Close reporting skill

Assembly checklist, structure, and writing standards for the month-end close package — executive memo, KPI dashboard, and board slides.

## What this skill covers

- Assembly checklist (inputs required before any deliverable is produced)
- Executive memo structure (period summary, key variances, close exceptions, cash, open items, sign-off)
- KPI dashboard layout (one-page Excel, grouped by Revenue / Margins / OpEx / Cash / Operating Metrics)
- Board snippet templates (financial summary, revenue bridge, variance explanations, cash position)
- Writing standards (plain English, active voice, favorable/unfavorable framing, one key number per board slide)

## Used by

Close Reporting Agent (primary). The last agent to run — depends on all four specialist agents completing their work first.

## Trigger phrases

"Assemble the close package", "write the executive memo", "build the KPI dashboard", "prepare board slides", "close reporting"
